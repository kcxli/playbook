# =============================================================================
# project-playbook — Python dependencies
# =============================================================================
# These versions are PINNED (==) so the environment is identical everywhere —
# your laptop, a teammate's machine, and the server. Do not loosen the pins
# without re-testing; ATS forms are brittle and a Playwright bump can change
# behavior.
#
# -----------------------------------------------------------------------------
# Full setup from a clean checkout (Linux server or macOS):
# -----------------------------------------------------------------------------
#   python3 -m venv .venv                       # create the virtual environment
#   .venv/bin/pip install --upgrade pip         # (optional) modern pip
#   .venv/bin/pip install -r requirements.txt   # install these packages
#   .venv/bin/python -m playwright install chromium
#                                               # ^ downloads the browser binary.
#                                               #   pip does NOT do this; it is a
#                                               #   separate ~150MB download.
#
# On a bare Linux server you may also need the browser's OS libraries:
#   .venv/bin/python -m playwright install-deps chromium   # needs sudo/root
#
# Verify it worked:
#   .venv/bin/python -m playbook_runner --help
# =============================================================================
